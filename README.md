## 📖 About the Project

**DClassroom** serves as a lightweight, clean, web-based frontend alternative for managing your school workflows. Built using raw HTML and structured components, it provides dedicated dashboards to keep your academic life organized without the clutter.

Live portal companion: [Google Classroom Home](https://sites.google.com/imas.edu.my/googlclassroom/home)

---

## 🚀 Key Features

*   🏠 **Central Dashboard:** A structured landing page layout designed for immediate access to classes.
*   📝 **To-Do Management:** A dedicated `Todo page.html` layout to track pending tasks, assignments, and deadlines.
*   📚 **Homework Hub:** Structured workspace (`homework page.html`) to isolate and manage individual assignments cleanly.
*   ⚡ **Lightweight & Fast:** Built entirely in static vanilla HTML for instant loading times and zero dependencies.

## 🛠️ Getting Started

### Prerequisites
To run this project locally, all you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Installation & Usage
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/OnyxSoul-1/DClassroom.git
   ```
2. Navigate into the project folder:
   ```bash
   cd DClassroom
   ```
3. Open `homepage classroom.html` in your favorite web browser to start exploring the custom dashboard interface.
